# Mori Kohi — Aki Matsuri 2026

A static, vanilla HTML/CSS/JavaScript site packaged with Vite.

## Development

```bash
npm install
npm run dev
```

Dev server: `http://localhost:3000`

## Production build

```bash
npm run build
npm run preview
```

Build output is written to `dist/`.

## Production-style server

```bash
npm start
```

This builds the site and serves `dist/`. `server.mjs` uses `PORT` when provided, otherwise port `3000`.

## Google AI Studio

Read `AI_STUDIO_IMPORT.md` before asking the Build agent to touch the project. The site is already designed; the import task is to preserve it and verify the runtime, not regenerate it.

## Variant

This package is the **white-background variant**. The primary paper/background surface is white while the existing autumn accent palette, dark night section, layout, content, and imagery remain unchanged.


## Variant note
This package is client-refined-v2: larger wordmark-only header crop, white/outlined 2025 memory cards, red Jalan Aman, and contact links in the footer.
